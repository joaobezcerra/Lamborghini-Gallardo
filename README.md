This document describes the operation of autonomous robot software developed for the Arduino platform using servo control and ultrasonic sensor libraries. The system uses digital pins to control the displacement motors, an audible signal, and a positioning motor for the distance sensor. The operating logic keeps the vehicle in constant forward motion until the sensor detects an object at a distance of thirty-five centimeters.

Upon encountering an obstacle, the code executes an immediate stop followed by a brief backward movement to ensure maneuvering space. Subsequently, the program activates the servo motor to rotate the sensor and measure the depth of the path to both the right and left. The algorithm evaluates which direction has the greater clearance and executes a turn in that direction for six hundred milliseconds before returning to forward motion.
